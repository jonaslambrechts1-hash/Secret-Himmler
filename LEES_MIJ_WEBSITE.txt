SECRET HIMMLER — als echte website (gratis, geen Claude, geen download)
========================================================================

Dit zet je spel om in een gewone website met een eigen link
(bv. secret-himmler.glitch.me). Iedereen opent die link gewoon in hun
telefoon-browser — Android, iPhone, maakt niet uit. Niemand hoeft iets
te installeren, ook Claude niet.

Je hoeft dit maar ÉÉN keer te doen. Daarna blijft de link werken.

OPTIE A — Glitch (makkelijkst, alles via de browser, geen account met
creditcard nodig)
------------------------------------------------------------------------
1. Ga naar https://glitch.com en maak een gratis account (mag met Google/
   GitHub-login).
2. Klik "New Project" → "Import from GitHub" bestaat ook, maar makkelijker:
   kies "New Project" → "glitch-hello-node" (een lege Node-app).
3. In de bestandenlijst links zie je server.js, package.json, etc. al
   staan van het sjabloon — vervang de inhoud van ELK bestand door de
   bijbehorende inhoud uit deze map (server.js, index.html, package.json,
   bundle.js, storage-polyfill.js, QuietCoup.jsx, entry-with-storage.jsx).
   Bestanden die nog niet bestaan in het sjabloon maak je aan via de
   "New File" knop (let op de exacte bestandsnaam, incl. hoofdletters).
4. Glitch start de app automatisch. Bovenin zie je "Show" → "In a New
   Window" — dat is je publieke link (iets als
   https://jouw-projectnaam.glitch.me).
5. Klik rechtsboven op "Share" om de link te kopiëren. Stuur die naar
   iedereen die meespeelt.

OPTIE B — Render.com (ook gratis, iets stabieler, wel een GitHub-account
nodig)
------------------------------------------------------------------------
1. Zet deze map (server.js, package.json, index.html, bundle.js,
   storage-polyfill.js, QuietCoup.jsx, entry-with-storage.jsx) in een
   nieuwe GitHub-repository (via github.com, "Upload files" — geen git-
   kennis nodig, gewoon slepen).
2. Ga naar https://render.com, maak een gratis account, klik
   "New +" → "Web Service", en kies die GitHub-repository.
3. Laat "Build Command" leeg en zet "Start Command" op: node server.js
4. Klik "Create Web Service". Na een paar minuten krijg je een link als
   https://secret-himmler.onrender.com — dat is je publieke website.

BELANGRIJK OM TE WETEN
------------------------------------------------------------------------
- Gratis hosting "slaapt" na een tijdje zonder bezoek en wordt wakker
  zodra iemand de link opent (kan een paar seconden duren de eerste keer).
- Actieve spelstatus wordt bewaard in een bestandje op de server, dus een
  korte herstart (slapen/wakker worden) gooit een lopend spel niet weg.
- Er is geen wachtwoord op room-codes — wie de code kent kan meespelen.
  Voor een potje met vrienden geen probleem.
- Wil je de site straks aanpassen (regels, teksten, kleuren)? Bewerk dan
  QuietCoup.jsx en vraag mij (of jezelf, met de esbuild-stap) om een
  nieuwe bundle.js te bouwen — dat kan ik ook gewoon opnieuw voor je doen.
